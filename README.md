# 🚀 SkillForge

SkillForge is a full-stack web application designed to help users build, manage, and track their skills in a structured way. The platform enables users to set learning goals, organize progress, and improve their personal and professional development.

This project demonstrates full-stack development with a clear separation between frontend and backend components.

---

## ✨ Features

- Add and manage skills  
- Set and track learning goals  
- Organized frontend and backend architecture  
- Clean and maintainable code structure  
- Scalable project design  

---

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Chelsi1056/SkillForge.git
cd SkillForge
```

---

### 2. Backend Setup

```bash
cd backend
pip install -r requirements.txt
python app.py
```

---

### 3. Frontend Setup

Open the `frontend` folder and run it using a local server,  
or open the `index.html` file directly in your browser.
